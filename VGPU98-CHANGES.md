# Changes for the VGPU98 2000 card

This branch, `vgpu98`, is 86Box with the VGPU98 2000 virtual graphics card added. It starts from 86Box commit `34af16415` (2026-10-09). The VGPU98 Project contributors made the changes below between 2026-10-09 and 2026-10-28. The card's BIOS, its Windows 98 drivers and its documentation are in [VGPU98-2000](https://github.com/streetgurudev/VGPU98-2000).

This is not an official 86Box build, and the 86Box project does not support it. Please report problems with it to [VGPU98-2000's issues](https://github.com/streetgurudev/VGPU98-2000/issues), not to 86Box.

## Files added

| Files | What they are |
|---|---|
| `src/video/vid_vgpu98.c` | The card: PCI, the VGA, the display engine, video memory, the settings, the log |
| `src/video/vid_vgpu98_gpu.c` | The GPU's command processor |
| `src/video/vid_vgpu98_r3d.c`, `vid_vgpu98_vtx.c` | The Direct3D device on the host GPU, and its vertex input |
| `src/video/vid_vgpu98_glide.c` | The Glide device |
| `src/video/vid_vgpu98_ogl.c` | The OpenGL device |
| `src/video/vid_vgpu98_disp.c`, `vid_vgpu98_dd.c` | The display on the host GPU, and its diagnostics |
| `src/video/vid_vgpu98_vk.c` | Loading Vulkan and choosing the host GPU |
| `src/video/vgpu98/*.vert`, `*.frag`, `*.comp` | The card's shaders, compiled to SPIR-V at build time |
| `src/include/86box/vid_vgpu98_dev.h`, `vid_vgpu98_vk.h` | The card's own headers |
| `src/include/86box/vid_vgpu98_card.h` | Generated by the VGPU98 project's card compiler from its card definition |
| `src/include/86box/vid_vgpu98_gpu.h`, `_glcmd.h`, `_glcpu.h`, `_oglcmd.h`, `_prog.h`, `_dispdiag.h` | Copied unchanged from the VGPU98 project's `card/` folder |
| `VGPU98-CHANGES.md` | This file |

## Files changed

| File | Change |
|---|---|
| `src/video/vid_table.c` | Lists the card among the video cards |
| `src/include/86box/video.h` | Declares the card's device; adds a count of screenshot requests to each monitor |
| `src/video/video.c` | Starts that count at 0 |
| `src/qt/qt_mainwindow.cpp`, `src/unix/sdl_monitor.c` | Count each screenshot request, so the card's diagnostics can capture at a screenshot |
| `src/include/86box/vid_svga.h`, `src/video/vid_svga.c` | A `host_display` flag: while the card composes its frame on the host GPU, the SVGA core renders no lines (its borders, blit and timing go on). It is kept apart from `override`, which pass-through cards use |
| `src/video/CMakeLists.txt` | Builds the card's sources, and compiles its shaders when glslang and the Vulkan headers are present (without them the card is built without 3D) |
| `src/cdrom/cdrom_image_viso.c` | Pads a folder mounted as a CD with 150 empty sectors after its last file, as CD mastering tools do |
| `src/qt/languages/86box.pot` and the 26 `.po` files | The card's setting texts, with empty translations |
| `README.md` | A note at the top saying this is an unofficial build |

86Box's window, renderer, settings dialog and other devices are otherwise unchanged. The license is 86Box's own: GPL version 2 or later ([COPYING](COPYING)).
